# Weekly Runbook

## Monday 08:00 MST — Automated (GitHub Action `weekly-analyst.yml`)

1. Run `scripts/funnel_analyst.py`
   - Queries entire Notion Job Search Tracker DB
   - Computes conversion at each stage:
     - Jobs surfaced → Applied
     - Applied → Screen scheduled
     - Screen → Final round
     - Final → Offer
   - Computes source performance (which boards yield interviews)
   - Generates `reports/weekly-YYYY-MM-DD.md`
   - Commits report to GitHub

2. Send weekly report email via SendGrid
   - Subject: `[Job Search] Weekly Report — YYYY-MM-DD`
   - Body: full report + link to Notion funnel view
   - Blake's mobile-friendly summary

3. Optional: Run Career Counselor
   - Analyze roles Blake was rejected from or didn't apply to
   - Identify skill gaps or positioning mismatches
   - Suggest 1-2 concrete actions for next week
   - Append to weekly report

## Blake's Weekly Action (Monday ~15 min)

1. Read weekly email digest
2. Review recommended action (usually one of):
   - Tweak scoring rubric if too many/too few Priority roles
   - Add new source if existing sources dried up
   - Update resume variant if market language shifted
   - Publish a LinkedIn case study if credibility gaps surfaced
3. Decide: continue current process or adjust one thing
4. Mark email as Done

## Mid-Week Check (Optional, Wednesday)

- Scan Notion for any stalled rows (Applied >5 days ago, no response)
- Consider a polite follow-up email for high-fit roles
- Log follow-up in Notion row Notes field

## End-of-Week Reflection (Optional, Friday)

- How many hours did Blake spend on job search this week?
  - Target: <2 hours (mostly reviewing Priority roles)
  - If >3 hours, automation isn't working — debug or simplify
- Any interviews scheduled for next week?
  - Block 30 min prep time per interview
  - Review prep doc generated by Interview Prep bot
- Update any compensation intel gathered during screens
  - Never in resume artifacts — only in Notion Notes field
